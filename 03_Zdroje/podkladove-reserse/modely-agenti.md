# Models, agents, ad-platform automation

Research for the talk "Umělá inteligence v reklamě". Research date: 2026-09-22. Scope: current models, agents and computer use, AI inside ad platforms, integrations. Campaigns, history/statistics and Czech examples/detection are covered by other research files.

Conventions:
- Status: VERIFIED-PRIMARY (read on the vendor's or benchmark owner's own page), VERIFIED-SECONDARY (read on a reputable secondary page only), UNVERIFIED, CONTRADICTED.
- "Vendor" means the number comes from the company selling the model or platform. "Independent" means a third party ran it (benchmark authors, Artificial Analysis, Zapier's leaderboard). Several "independent" benchmarks are still run on vendor-supplied settings; this is noted per row.
- Access notes: openai.com and help.openai.com block direct scripted downloads. Their pages were read through a text-rendering proxy (r.jina.ai) of the original URL, and publication dates were cross-checked against the first Wayback Machine capture. Anthropic, Google, Meta and benchmark pages were read directly.

## 1. Summary

1. **Names.** "Cloud Opus 5.5" is **Claude Opus 5.5** (Anthropic), released 2026-09-22, the research date; API `claude-opus-5-5`, also on AWS, Google Cloud and Microsoft Foundry; in the Claude app on Pro, Max, Team and Enterprise, not Free [M1–M3]. "ChatGPT Astra 6" is **GPT-6 Astra** (OpenAI), rolling out since 2026-09-03; API `gpt-6-astra`. In ChatGPT's Chat view it is labelled **GPT-6 Pro** (Pro, Business, Enterprise); Plus users get it only in ChatGPT Work and Codex [M8, M9]. Smaller GPT-6 Sol and Luna launched the same day [M10]. Google's newest model is Gemini 3.8 Flash (2026-09-02); its Pro tier is still Gemini 3.1 Pro in preview [M16].
2. **Model ≠ app ≠ tool.** Both flagships take text and images in and give text out [M4, M11]. Pictures in ChatGPT come from a separate image model (ChatGPT Images 2.5 / GPT-Image-2.5, 2026-09-08, all tiers, C2PA metadata) [M13]. Claude cannot generate images at all; Claude Design builds layouts, slides and campaign visuals from code [M5, M7]. OpenAI currently has no video generator: the Sora app closed 2026-04-26 and its API closes 2026-09-24 [M14].
3. **Head to head, the two are close.** Each vendor's own table shows its model ahead. On the one business-workflow benchmark a neutral party ran for both (Zapier AutomationBench, 47 tools incl. marketing), GPT-6 Astra scores 41.4% and Claude Opus 5.5 40.0%, so about 6 in 10 workflows still fail [M24]. Artificial Analysis's index puts Opus 5.5 at 58 and Astra at 53 [M26].
4. **No benchmark measures ad quality or Czech.** The multilingual test both vendors use (MMMLU) has 14 languages and Czech is not one; neither vendor publishes a Czech score [M30]. The talk's own side-by-side test is the only evidence for Czech copy.
5. **Computer-use trend (OSWorld).** Best reported scores rose from 12% (April 2024, paper) through 38% (Jan 2025) to 42% (May 2025) on the original test, and on OSWorld-Verified from 61% (Sep 2025) to 75% (GPT-5.4, March 2026, first vendor claim above the 72.4% human baseline) and 78.7% (GPT-5.5, April 2026) [M21, M22, M54–M57]. Anthropic's 83.4% (May 2026) used a changed test method [M23].
6. **Reality check.** OSWorld v1 tasks take a person about 2 minutes. OSWorld 2.0 (June 2026) uses workflows that take a person about 1.6 hours: the best fully completed share on the independent leaderboard is 31% (release v2026.08.08) or 44% (newest release v2.1), and in the authors' length analysis (models one generation older) every model scored zero on tasks over about 163 minutes [M19, M20]. Opus 5.5 and Astra are not on that leaderboard yet.
7. **Vendor numbers are not comparable.** The same model, Claude Opus 5, appears on OSWorld 2.0 as 68.3% (benchmark authors), 70.2% (OpenAI's run), 70.6% and 74.0% (Anthropic, two dates). Astra's 72.6% and Opus 5.5's 81.8% come from different task sets and grading [M17, M18, M58].
8. **Agents are in the products now.** Claude in Chrome is generally available on all paid Claude plans (2026-08-26) and can act without per-step approval under a safety classifier [M33]. ChatGPT Work has a cloud browser (paid plans) and agent mode (Plus 40, Pro 400 tasks a month); the separate Atlas browser closed 2026-08-09 [M15, M36, M37].
9. **Money stays with a human.** Claude in Chrome is prohibited from purchases, financial transactions and creating accounts [M34]. ChatGPT asks before any financial, legal or account commitment [M36]. Both vendors warn about prompt injection from web pages [M35, M38, M39].
10. **The API route to ad accounts.** Meta's official ads MCP server (open beta since 2026-04-29) lets Claude or ChatGPT create campaigns, ad sets and ads, but everything is created paused; activation "starts spending budget" and the AI client asks for confirmation; business admins can block actions or cap budgets [M42–M46]. Google's official Ads MCP is strictly read-only [M40]. TikTok's MCP (~400 tools) advertises workflows "without human intervention at every step"; Amazon's MCP builds campaigns that "only need review and approval" [M110, M117].
11. **The platforms generate ads themselves.** Google's AI Max writes and serves headlines in all Google Ads languages without per-asset approval, and Demand Gen auto-generated videos are on by default [M64, M67, M72]. Meta's Advantage+ creative has image, text and video generation, some on by default [M96]. TikTok Symphony Creative Studio is generally available [M107]. Sklik's Chytrá kampaň, driven by "Seznam AI", has been open to all advertisers since May 2026 and proposes all ad texts from a website [M121].
12. **Meta's "fully automated ads by end of 2026".** This was a WSJ report from unnamed sources (June 2025). By September 2026 no such product has launched; the Cannes 2026 end-to-end creative solution is still in testing [M88, M93, M94]. Meta's own numbers (operator claims): over 9 million small businesses use at least one AI creative tool, Advantage+ runs above $75 billion a year [M92].
13. **Ads inside AI assistants.** ChatGPT shows ads to Free and Go users only (test from 2026-02-09); it expanded to 31 European countries in late August 2026, Czech Republic is listed for self-service advertisers, and there are no personalized ads in the EEA at first [M126, M128–M130]. Google's ads inside AI Overviews run in 12 English-language markets, none in the EU [M83]. Seznam shows Sklik ads under Seznam Asistent answers since June 2026 [M123].
14. **"Can AI create and publish an ad by itself?"** Create: yes, generally available on every major platform and in ChatGPT. Publish alone: no first-party product documents it; each flow keeps an opt-in, a publish click, a paused default or an approval. No independent end-to-end test was found; independent studies cover creative performance only (e.g. AI Max: +13% conversion value at +16% cost per conversion) [M131, M132].
15. **To the CRM.** Workflow tools move results, not campaigns: Zapier can pass Google and Meta lead-form entries to a CRM and send offline conversions back, but cannot create Google campaigns or ads [M48]. Google Ads API access now hangs on a Google Cloud project; developer tokens were retired on 2026-09-09 [M78].

## 4. Chart datasets

What OSWorld measures: an agent gets a real desktop (Ubuntu with Chrome, LibreOffice, VS Code and other apps), sees screenshots and must finish a task with mouse and keyboard; a script checks the end state. What it does not say: nothing about ad quality, persuasion, brand fit or Czech. OSWorld v1 tasks are short (median about 2 minutes for a human), so "above human baseline" on OSWorld-Verified does not mean an agent can run a 2-hour campaign setup alone. OSWorld 2.0 (June 2026) uses long workflows (median about 1.6 hours for a human) and shows much lower full-completion rates [M20].

Three variants exist and must not share one line:
- **OSWorld** (original, 369 tasks, April 2024). Scores depend on the step budget (15, 50, 100 steps).
- **OSWorld-Verified** (2025-07-28): in-place upgrade that fixed 300+ task and grader issues [M53]. Anthropic's own chart marks the switch: "Scores prior to Claude Sonnet 4.5 were measured on the original OSWorld; scores from Sonnet 4.5 onward use OSWorld-Verified." [M56]
- **OSWorld 2.0** (2026-06-26): new benchmark with 108 long tasks, several task releases (v2026.06.24, v2026.08.08, v2.1), two metrics (binary completion, partial score). Vendors report different releases and settings; OpenAI's and Anthropic's OSWorld 2.0 figures are not comparable with each other [M17, M18].

Recommended chart [I]: series A and B as one time axis with a visible break and label at 2025-07-28, human reference line at 72.4%. A separate small panel with series C (independent OSWorld 2.0 binary completion) as the reality check. Do not plot series D as a line; use it only as a footnote table.

## 5. Agent workflow: brief → copy + visual → variants → ad system → CRM/e-shop

Worked example: the talk's fictional lemonade ZÁTOKA, a Meta campaign plus a Google Search campaign, leads and orders flowing back to a CRM and e-shop.

Three ways an AI can act, which the slide should keep apart:
- **UI control (computer use)**: the agent looks at screenshots and clicks in the same web interface a person uses (Claude in Chrome, ChatGPT Work cloud browser, ChatGPT agent mode, API computer-use tools). Works on any website, is slower, and is limited by the agent vendor's safety rules and the website's own blocking of bots [M33–M39].
- **API integration**: the agent calls the ad platform's official interface. Meta now offers an official MCP server that can create and edit campaigns; Google's official MCP server only reads data, so creating Google campaigns by API still means the Google Ads API with a developer token [M40–M46].
- **Automated workflow**: fixed rules in Zapier, Make or n8n move data between systems. Good for leads and conversions, not for building campaigns: Zapier's Google Ads actions cannot create campaigns or ads, n8n's Google Ads node only reads campaigns [M48, M49].

"AI can publish it alone" is not what any first-party product documents: each flow keeps an opt-in, a publish click, a paused default or an approval. TikTok's MCP documentation comes closest to unattended operation. No independent end-to-end test was found.
